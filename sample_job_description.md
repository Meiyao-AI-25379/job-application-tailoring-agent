# Junior Software Engineer

**Company:** Example Digital Services  
**Location:** Melbourne, VIC (Hybrid)  
**Employment type:** Full time

This is a fictional job advertisement for demonstration.

## About the role

Join a small team building internal tools for service operations. You will help implement and test API endpoints, maintain SQL queries and document changes for colleagues.

## Required

- Experience writing Python through coursework, projects or work.
- Ability to write SQL queries using joins and aggregations.
- Experience testing software changes and documenting how to reproduce or verify them.
- Full Australian working rights.

## Desirable

- Experience building REST APIs with FastAPI or a similar framework.
- Familiarity with Git and code review.
- Exposure to deploying applications on a cloud platform.

## How to apply

Submit a CV and a short cover letter describing one project you contributed to.
